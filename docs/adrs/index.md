# Architecture decisions

Sdlicit records its own architectural decisions the same way it asks users to record theirs: as MADR format ADRs, in `.sdlicit/artifacts/adr/` at the repository root, using the same format the tool itself generates and parses (`helpers/parsers.py::parse_madr_content`).
